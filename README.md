# 📚 Library Management System

A modern **Library Management System** built with **Spring Boot**, **Spring Security**, **Thymeleaf**, **Spring Data JPA**, **MySQL**, and **Bootstrap 5**.

Designed to provide a secure, responsive, and user-friendly experience for managing books with role-based access control.

---

## ✨ Features

* 🔐 Custom Login & Logout
* 👥 Role-Based Authorization (USER, LIBRARIAN, ADMIN)
* 📚 Add, Update, Delete & Search Books
* 🔍 Smart Search Functionality
* ✅ Form Validation
* 🚫 Custom Access Denied Page
* 🎨 Responsive Bootstrap 5 UI
* 🔔 SweetAlert Notifications

---

## 🛠 Tech Stack

* Java
* Spring Boot
* Spring MVC

* Hibernate
* Thymeleaf
* MySQL
* Bootstrap 5
* Maven

---

## 👤 User Roles

| Role          | Permissions                    |
| ------------- | ------------------------------ |
| **USER**      | View & Search Books            |
| **LIBRARIAN** | Add & Update Books             |
| **ADMIN**     | Full Access (including Delete) |

---

## 🚀 Getting Started

```bash
git clone https://github.com/mohdmufeed/Library-Management-SpringBoot-Thymeleaf.git
```

Configure your MySQL database in `application.properties`, then run the Spring Boot application.

Open:

```
http://localhost:8080/books/
```
